One original line describing a hilariously useless superpower: the power to stop time with a single thought — a thought that only ever arrives while already late. A tiny deterministic Python program writes that single line (112 characters, no trailing newline) to `entry.txt`.

## Run it

```bash
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (default `/output`):

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
